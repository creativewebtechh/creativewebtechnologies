# Creative Web Technologies

Digital Products. Built for Growth.

A full-service software development company building modern websites, web applications, mobile apps, and custom digital solutions for businesses.

## Tech Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3
- React Router 7
- Framer Motion
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
